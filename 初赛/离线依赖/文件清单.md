# 离线依赖清单

本目录保存 12 个依赖二进制，以及 `传输清单.json`、本清单、`恢复.sh`、`release-assets.json` 四个文件。二进制文件名与 `工程源码/附件/submission.json` 的 `store_path` 保持一致（`flash_attention/` 子目录在 AFS 上保留，仓库内为扁平名），因此**无需改名**即可直接使用。

`run.sh` 会调用 `恢复.sh`，按以下顺序查找依赖并逐个校验 SHA256：

1. 本目录同名文件；
2. `$IFAB_AFS_HOME`（或 `$IFAB_AFS_HOME/songshan`）下按 `工程源码/附件/submission.json` 的 `store_path` 命名的文件。

校验通过后展开到 `工程源码/附件/offline/`：本目录或普通机器上的文件复制过去；依赖已位于 AFS 时建立符号链接，避免重复复制 913 MB。

## 从 GitHub Release 获取（克隆仓库后必做）

Git 仓库不含 12 个二进制（单文件超出 GitHub 100 MB 硬限制），它们挂在 Release [`v0-r10-deps`](https://github.com/ryukimzl/songshancup-minimax/releases/tag/v0-r10-deps) 上。**Release 资源名与本目录文件名完全一致**，从发布页下载后直接放进本目录即可，`恢复.sh` 会按 `传输清单.json` 校验。

可选：命令行批量下载（需要 curl）：

```bash
cd 初赛/离线依赖
for n in build_tool_xmake.tar.gz python_deps_base.tar.gz python_deps_models.tar.gz \
         python_deps_metrics.tar.gz triton_dtk2604.whl \
         flash_attention.whl.part0{0,1,2,3,4,5,6}; do
  curl -fL --retry 3 -C - -o "$n" \
    "https://github.com/ryukimzl/songshancup-minimax/releases/download/v0-r10-deps/$n"
done
```

## 平台放置方式

- 推荐：把初赛提交整个目录放在个人 AFS（`$IFAB_AFS_HOME`），直接 `bash run.sh build-core`，本目录已含全部二进制，无需额外准备。
- 若必须使用 InfiniFabric 平台“项目”：项目复制总上限为 128 MiB（使用手册第 37.1 节），只传 `run.sh`、`工程源码/` 和本目录的 `传输清单.json`、`文件清单.md`、`恢复.sh`、`release-assets.json`；12 个二进制按 `store_path` 放在 AFS 根目录（`build_tool_xmake.tar.gz`、`python_deps_base.tar.gz`、`python_deps_models.tar.gz`、`python_deps_metrics.tar.gz`、`flash_attention/triton_dtk2604.whl`、`flash_attention/flash_attention.whl.part00` 至 `part06`），入口会自动校验并建立链接。
