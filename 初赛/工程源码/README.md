# FL2VA分阶段复现

在比赛指定的Linux/Python3.11海光八卡环境，分别提交三个作业：

```bash
bash run.sh build-core
bash run.sh build-lm
bash run.sh native
```

每次只跑所选阶段，成功后再进入下一阶段；失败停止，不自动重试。平台入口统一选run.sh，参数依次填build-core、build-lm、native。无参数只显示帮助。

单项作业可设28分钟，内部27分钟保护另最多45秒收尾；不保证首次冷编译一定完成。配套构建自动存入个人持久存储fl2va-r10-submission，新作业继续使用它，不依赖上次临时目录。

native自动寻找统一模型与首帧，找不到时按提示指定；构建不需要模型和首帧。依赖已随材料附带，无需手工安装。

视频、运行日志和评测结果由native生成到 `结果/本次运行/`；本交付不附这些可生成文件。生成后可用 `bash run.sh check` 只比较已有视频。参考视频属于评测输入，保留在附件/参考中，不是本次参赛输出。

源码、依赖、补丁与必要配置在附件，技术方案见技术报告。模型权重和出题方首帧由比赛环境提供。原始实验记录保留在本地项目，不重复提交；若提交页面要求上传输出示例和运行日志，运行native后从结果/本次运行取得。

当前官方阈值、VAE许可和海光九齿调用证据仍待确认。新入口仅完成本地控制检查，真实平台重建尚未验收。
